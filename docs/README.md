# Documentation

This directory contains the foundational planning and technical strategy for the VisionVR project.

## Contents

- `product-brief.md` — product vision, users, problem statement, and value proposition
- `requirements.md` — MVP scope, user needs, acceptance criteria, and non-goals
- `roadmap.md` — 30/60/90-day roadmap and delivery phases
- `architecture.md` — system structure and high-level technical design
- `research.md` — headset compatibility, frameworks, and exploration notes

## Purpose

The docs are intended to align the project around a realistic first release: a spatial productivity and workspace platform for ordinary VR headsets rather than a complete Vision Pro clone.
