# Product Brief

## Vision

VisionVR is an open spatial XR platform that enables productivity and immersive workflows on standard VR headsets. The goal is to provide a lightweight, customizable spatial workstation that feels natural on common hardware while remaining flexible enough for future app and SDK expansion.

## Problem

Most VR users have access to headsets that are capable but not designed for immersive productivity workflows. The existing landscape is fragmented across headsets, operating systems, and app ecosystems. There is a need for a unified layer that brings desktop-like spatial workspaces, floating windows, and UI overlays to mainstream VR hardware.

## Target users

- remote workers who want a larger virtual workspace
- students and trainers using collaborative immersive environments
- developers exploring XR interfaces and modular interaction systems
- creators testing spatial productivity workflows on accessible hardware

## Core value proposition

VisionVR provides:

- a spatial workspace for apps and multitasking
- controller or hand-driven interaction patterns
- minimal passthrough-based overlays for context awareness
- a compatibility layer across mainstream VR hardware

## MVP direction

The first release should focus on a productivity-oriented experience rather than a full mixed-reality ecosystem. Recommended MVP:

- VR app launcher
- 3D floating windows
- workspace docking and management
- basic hand/controller input
- minimal overlay layer

## Strategic positioning

VisionVR should not try to recreate a proprietary product exactly. Instead, it should create a unique spatial layer that is open, customizable, and practical on regular VR hardware.
