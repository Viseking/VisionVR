# Roadmap

## Phase 0 — Foundation and strategy

- Define product brief
- Choose target headset stack
- Finalize MVP scope
- Draft architecture and requirements
- Create repo structure and planning docs

## Phase 1 — Research and prototyping

- Test headset compatibility and input assumptions
- Prototype floating app windows
- Validate motion and interaction comfort
- Create a basic spatial workspace model

## Phase 2 — Core software platform

- Device abstraction layer
- Input layer for hand tracking and controllers
- Window manager
- XR scene runtime
- Interaction system
- App lifecycle and workspace persistence

## Phase 3 — Hardware feasibility

- Evaluate compatibility requirements
- Define accessory, sensor, and passthrough needs
- Document BOM and hardware constraints

## Phase 4 — MVP validation

- Test with users
- Measure latency, comfort, and usability
- Refine UI scale and spatial ergonomics
- Prepare showcase demo

## Phase 5 — Expansion

- Multi-user collaboration
- App ecosystem and developer SDK
- Advanced profiles and custom environments
- More powerful spatial productivity features
