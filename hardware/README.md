# Hardware

This folder is reserved for design documentation, feasibility work, and hardware-related planning.

## Current intent

- evaluate headset compatibility patterns
- design accessory concepts when needed
- track BOM and hardware feasibility
- separate physical constraints from software platform planning

## Suggested subfolders

- `designs/` — concept sketches, design notes, and 3D or visual references
- `schematics/` — hardware interface documentation and electrical references
- `BOM/` — bill of materials and parts list tracking
